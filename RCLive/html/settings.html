Maximum laps to chart: Setting this too high may cause performace issues when plotting graphs.
Audio Volume: Adjust the volume for in-race announcements between 0 and 100.
Race Control Password: Password enables selecting the flag to pause and re-start the race.






Tips:
Selecting a drivers name will display a summary of all heats raced.
On the live race page selecting the graph will toggle between laptimes and position.
If the password is configured then the race can be started/paused and next heat selected using the call button or the flags icon.
